# Partial Freezing of a Multilingual Distilled Model for Persian POS Tagging

**Researcher:** Kiarash Ghaderi

## Overview

This project investigates the impact of partial Transformer-layer freezing on multilingual DistilBERT fine-tuning for Persian Part-of-Speech tagging.

The experiments compare full fine-tuning against freezing the lower three Transformer blocks while keeping embeddings, upper blocks, and the classification head trainable.

## Dataset

- UD Persian PerDT
- 12,000 training sentences sampled using seed 42
- 1,456 validation sentences
- 1,455 test sentences

Official source:
https://github.com/UniversalDependencies/UD_Persian-PerDT

## Model

`distilbert/distilbert-base-multilingual-cased`

## Experimental Results

| Metric | Full Fine-tuning | Partial Freezing |
|---|---:|---:|
| Test Accuracy | 96.36% | 95.78% |
| Test Macro F1 | 88.73% | 88.07% |
| Trainable Parameters | 134.75M | 113.48M |
| Train + Dev Evaluation Time | 779.50s | 674.81s |

These are preliminary single-seed results.

Partial freezing reduced measured execution time by 13.43%, with a decrease of approximately 0.584 percentage points in test accuracy.

## Reproducibility

Python 3.11.9 and NVIDIA RTX 3050 6GB Laptop GPU were used.

The executed notebook records data checksums and experiment metadata.

Model checkpoints and downloaded raw datasets are excluded from this repository. They can be regenerated by running the notebook.

## Limitations

The main comparison uses one random seed and one freezing configuration. The rare UPOS label `X` has only one test instance. Further experiments are necessary before drawing general conclusions.

## Macro-F1 Sensitivity Analysis

The primary evaluation reports macro-F1 across all 16 UPOS classes.
A supplemental sensitivity analysis excludes class `X`, which has
only one instance in the test set.

| Metric | Baseline | Partial Freezing |
|---|---:|---:|
| Macro F1 - All 16 classes | 0.887309 | 0.880732 |
| Macro F1 - Excluding X | 0.946463 | 0.939448 |

Excluding `X` is a supplemental analysis only. The primary result remains
the macro-F1 score across all 16 classes. See
`results/macro_f1_sensitivity.csv` for the recorded values.
